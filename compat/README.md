# Released-host compatibility

Version 1.1.0 uses released Genex 0.1.12 plugin API 3. No host patch is needed.

The old 1.0.x releases needed unreleased customization/footer/navigation APIs and cannot be installed on stock Genex. Their source and reference patches remain in their immutable historical tags. The current package uses supported settings panels instead.

The renamed id is a new catalog identity; existing history stays in the Genex profile. A custom profile setting must be entered again after installing the new id. See the root README for installation and verification.
